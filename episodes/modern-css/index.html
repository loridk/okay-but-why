Episode guide

Modern CSS — Wait, CSS Does That Now? Series

Start at Episode 1 or jump directly to any Modern CSS — Wait, CSS Does That Now? topic. Each page includes the audio, transcript, and code cards.

  • Episode 1: What Happened to CSS? How CSS evolved beyond older workarounds; browser support, progressive enhancement, component-aware styling, and the continuing role of tooling.
  • Episode 2: CSS Variables — Oh, So Sass Variables Aren't the Same Thing Runtime custom properties versus build-time Sass variables; cascade, inheritance, fallbacks, themes, registration, and accessible design tokens.
  • Episode 3: Flexbox and Grid — We Can Stop Abusing Floats Now Choosing normal flow, Flexbox, Grid, and subgrid; sizing, alignment, wrapping, and preserving meaningful source order.
  • Episode 4: Responsive CSS Without Seventeen Breakpoints Fluid layouts with intrinsic sizing, auto-fit/auto-fill, min(), max(), clamp(), viewport units, and content-driven breakpoints.
  • Episode 5: Container Queries — The Component Finally Knows Where It Lives Make components respond to their own available space using query containers, names, units, and progressive enhancement.
  • Episode 6: Selectors Got Weirdly Powerful — :has(), :is(), :where() and Friends Use :has(), :is(), :where(), and :not() while understanding specificity, state, semantics, and selector tradeoffs.
  • Episode 7: The Cascade Strikes Back — Specificity, Layers, Scope and Nesting How cascade precedence, specificity, layers, scope, and native nesting solve different styling problems.
  • Episode 8: Sass in 2026 — Are We Still Doing This? What Sass still adds through modules, mixins, and functions; distinguish build-time work from runtime CSS and evaluate migration costs.
  • Episode 9: PostCSS — Wait, This Isn't Another Sass, Right? PostCSS as a plugin pipeline; Autoprefixer, browser targets, configuration, and the difference between processing CSS and supplying runtime support.
  • Episode 10: Tailwind — Why Are There 900 Classes in My HTML? Why utility classes appeal, how variants and class detection work, and when Tailwind's conventions help or complicate a project.
  • Episode 11: Logical Properties — CSS That Stops Assuming Everyone Reads Like You Inline/block directions, logical spacing and sizing, writing modes, and avoiding assumptions about reading direction.
  • Episode 12: Modern Color — CSS Learned Math and Developed Opinions About Purple Color spaces, OKLCH, wider gamuts, color-mix(), relative colors, fallbacks, and why contrast still needs testing.
  • Episode 13: Animation Without Making Everyone Sick Transitions, keyframes, performance, view transitions, scroll-driven animation, and purposeful motion that respects reduced-motion preferences.
  • Episode 14: So… Do We Even Need a CSS Framework? Compare plain CSS, component frameworks, utilities, CSS Modules, CSS-in-JS, Sass, and PostCSS against actual project needs.
