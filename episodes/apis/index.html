Episode guide

APIs — How Software Talks to Other Software Series

Start at Episode 1 or jump directly to any APIs — How Software Talks to Other Software topic. Each page includes the audio, transcript, and code cards.

  • Episode 1: Okay, What Actually Is an API? APIs as contracts and boundaries, from libraries and browser interfaces to operating systems and remote services.
  • Episode 2: Why Did We Need Web APIs? The progression from server-rendered forms to AJAX and shared backends; separating data from pages and recognizing the costs.
  • Episode 3: HTTP: The Thing Underneath the API Requests and responses, methods, headers, bodies, status codes, network failures, and uncertain timeout outcomes.
  • Episode 4: REST: Who Asked for This? Resources, safe and idempotent methods, stateless requests, caching, layers, and concurrent edits.
  • Episode 5: JSON: Why Are We Passing This Stuff Around Everywhere? Serialization, JSON versus JavaScript objects, parsing versus validation, numbers, dates, and deliberate public data shapes.
  • Episode 6: Calling an API From JavaScript Promises, async/await, fetch, response handling, loading states, cancellation, races, and responsible retry behavior.
  • Episode 7: Building an API Routes and handlers, input validation, authorization, business logic, database boundaries, errors, and testing the contract.
  • Episode 8: Authentication: How Does the API Know Who the Hell I Am? Authentication and authorization at the API boundary; credentials, sessions, and tokens as mechanisms with distinct responsibilities.
  • Episode 9: OAuth: Why Is "Sign In With Google" So Complicated? Delegated authorization and sign-in flows; follow the redirects, separate protocol stages, and protect the application's decisions.
  • Episode 10: CORS: Why Is My Browser Yelling at Me? Origins, browser response-reading restrictions, preflights, credentialed requests, and why CORS is not authentication.
  • Episode 11: Webhooks: What If the API Calls You? Event delivery versus polling; verification, retries, duplicate and out-of-order events, durable acceptance, and recovery.
  • Episode 12: REST Isn't the Only Option GraphQL, RPC/gRPC, WebSockets, server-sent events, and streaming as choices solving different communication problems.
  • Episode 13: API Design: Don't Make Other Developers Hate You Consistent contracts, useful errors, pagination, filtering, rate limits, idempotency, compatibility, and documentation.
  • Episode 14: Modern APIs: AI, MCP, and "Wait, Isn't This All Just APIs Again?" Model APIs, SDKs, streaming, tool calls, MCP roles and discovery, agent decisions, and trust boundaries.
Okay, But Why? — Tech concepts without the ceremonial fog.
