Episode guide

JavaScript Testing Series

Start at Episode 1 or jump directly to any JavaScript Testing topic. Each page includes the audio, transcript, and code cards.

  • Episode 1: Why Are We Testing Code That Already Works? Automated checks as repeatable evidence; regressions, meaningful failures, refactoring confidence, manual testing, and choosing checks by risk.
  • Episode 2: Unit Tests — How Tiny Is Tiny? Behavioral boundaries, pure functions and side effects, input/output contracts, boundary cases, runtime validation, nonmutation, and testable seams.
  • Episode 3: Arrange, Act, Assert — The Testing Sandwich Readable setup, action, and expected outcomes; meaningful test names, fixtures, hooks, cleanup, table-driven tests, and independent scenario state.
  • Episode 4: Jest, Vitest, and Who Actually Runs This Stuff? Test runners, assertion libraries, environments, transformations, npm scripts, test discovery, watch mode, CI, and Node's built-in runner.
  • Episode 5: Mocks, Stubs, Spies, and Other Lies We Tell Our Code Test doubles, dependency injection, controlled answers, recorded interactions, spies, module mocking, cleanup, and the danger of contract drift.
  • Episode 6: Testing the DOM Without a Browser — Mostly jsdom, DOM Testing Library, accessible queries, user-event, native controls, keyboard behavior, focus, status updates, and the limits of simulated DOM testing.
  • Episode 7: React Testing — Stop Interrogating the Furniture Testing real React state and public component behavior through props, controlled components, callbacks, rerendering, providers, effects, cleanup, and Strict Mode.
  • Episode 8: Async Tests — The Test Finished Before the Bug Arrived Promise completion, async assertions, HTTP and network failures, condition-based waiting, race conditions, fake timers, debounce, cleanup, and flaky-test diagnosis.
  • Episode 9: Unit, Integration, End-to-End — Which Wires Are Connected? Test scope versus environment, real collaborators and replaced dependencies, API/database boundaries, browser journeys, smoke checks, and choosing the narrowest useful scope.
  • Episode 10: One Hundred Percent of What? — Coverage and the Limits of Tests Line, statement, function, and branch coverage; assertion strength, thresholds, mutation testing, property-based testing, and what a green test suite cannot prove.
Okay, But Why? — Tech concepts without the ceremonial fog.
