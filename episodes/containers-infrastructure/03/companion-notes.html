Companion reference

A Linux container isolates processes while sharing its hosting Linux kernel. It is not simply a small VM.

Key terms

Host
The system running the container runtime; it may itself be a VM.
User space
Application software, runtimes, and libraries above the kernel.
Container runtime
Software that executes and manages containers.
Docker
Tools and an ecosystem for building, distributing, and running containers; not the whole concept of containers.

Compare the boundary

  • VM: virtual hardware and a guest OS with its own kernel.
  • Linux container: isolated process environment using an existing Linux kernel.
  • Desktop Linux containers: commonly run within a Linux VM or WSL 2 environment on a non-Linux desktop.

Portability still depends on OS and CPU compatibility, runtime support, configuration, and external services. Isolation depends on permissions and configuration; privileged containers and sensitive host mounts can weaken the boundary.
