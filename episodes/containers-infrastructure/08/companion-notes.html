Companion reference

Orchestration becomes useful when coordinating workloads across infrastructure is itself a substantial operational problem.

Key terms

Scheduling
Choose an eligible machine using resource requests and placement rules.
Reconciliation
Repeatedly work to reduce the gap between desired and observed state.
Service discovery
Give clients a way to find changing workload destinations.
Scaling
Change workload capacity; automatic scaling needs explicit configuration and suitable signals.

Problem → mechanism

  • Instance disappears → maintain a desired replica count.
  • New workload needs a machine → scheduling.
  • Instance addresses change → service discovery.
  • New release must preserve capacity → configured rolling replacement.
  • Traffic changes → evaluate scaling and the actual bottleneck.

Docker tooling can build images used by Kubernetes. Kubernetes uses compatible container runtimes through CRI; it does not require Docker Engine on every node. Removing dockershim did not invalidate ordinary Docker-built images.

Recovery requires capacity, working dependencies, valid configuration, and an appropriate data strategy. Kubernetes does not supply application correctness, automatic database replication, or a staffed operations team.
