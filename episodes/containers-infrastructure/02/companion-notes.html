Companion reference

Virtualization lets isolated machine environments share physical hardware. Sharing a physical host remains a common failure boundary.

Key terms

Hypervisor
Creates and manages virtual machines and mediates access to physical resources.
VM
A virtualized machine environment with a guest operating system and kernel.
VPS
A hosted private server environment; implementation, management, and guarantees vary by provider.
Isolation
Boundaries around visibility, changes, permissions, and resource use—not a promise that failures cannot cross any boundary.

Conceptual hierarchy

Physical hardware supports a hypervisor, which manages VMs. Each VM has a guest OS that runs applications. Hosted hypervisors also involve a host OS.

Questions for a hosting plan

  • Who patches the OS and runtime?
  • Which resources are allocated, shared, or capped?
  • What happens after host failure?
  • Who creates backups and tests restoration?
