Companion reference

Choose how much infrastructure to operate yourself. Managed services change the division of responsibility; they do not remove your application and data responsibilities.

Key terms

Compute
Execution capacity: VMs, managed container execution, functions, and other models.
Storage
Block, file, and object interfaces support different workloads.
Load balancer / CDN
Distributes traffic among backends / delivers and caches appropriate content nearer users.
Region / availability zone
Geographic deployment area / provider-defined separated location or failure domain within a region.

Responsibility spectrum

  • IaaS: infrastructure building blocks; you commonly operate the guest OS and application.
  • PaaS: application platform; more runtime and deployment work is managed.
  • SaaS: a finished hosted application.
  • Managed containers: run images with platform-managed operations that vary by service.
  • Managed Kubernetes: Kubernetes with a service-specific division of cluster responsibilities.
  • Serverless: abstracts server provisioning and capacity management; execution constraints, state, permissions, and costs still matter.

Before choosing

Compare maintenance ownership, identity permissions, monitoring, recovery, latency, data location, transfer charges, workload limits, and exit costs. Multiple replicas or zones help only when the application and its dependencies are designed to use them.
