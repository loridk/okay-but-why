Companion reference

A deployed application ultimately runs as processes on computers. A static site still needs software to serve its files, even when its build tools do not run in production.

Key terms

CPU / RAM / storage
Instruction execution / active working memory / persistent files.
Operating system
Manages processes, memory, files, devices, and networking.
Runtime
Executes the application in its required environment, such as Node or PHP.
Server / hosting / cloud
Service-providing software or machine / an arrangement for serving software or content / a model for obtaining infrastructure and services.

Trace the local request

  1. The browser requests the episode list from a local listening port.
  2. The operating system delivers the connection to the server process.
  3. The runtime executes application code and returns a response.
  4. Stopping the process leaves source files on disk but removes the running service.

Build tools and deployed runtimes are separate decisions. Browser JavaScript executes on the visitor’s machine.
