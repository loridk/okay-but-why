Companion reference

Version-control the intended infrastructure. Review the proposed actions. Protect state and data separately.

Key terms

Configuration drift
Actual settings diverge from intended or recorded settings.
Provisioning
Create or allocate infrastructure resources.
Provider
Integration that communicates with a service API to manage resources.
State
Mapping and recorded information connecting logical definitions to real resources; may include sensitive data.

Repeatable workflow

Terraform and OpenTofu commonly use HCL-style declarative configuration. The workflow below is a concept diagram, not executable configuration.

Keep the boundaries clear

  • Normal plan/apply runs are triggered work, not inherently continuous reconciliation.
  • Git history does not undo external data changes.
  • Provisioning a database does not restore its contents.
  • Sensitive output flags do not guarantee absence from state.
  • Protect state and plan files; coordinate team access and locking.
  • Failed applies can leave partial changes; inspect before retrying.
