Companion reference

Identify the caller before choosing an address. In an ordinary isolated container network, localhost points back into that container’s network context.

Key terms

Published port
A route from a host address and port to a container port.
Environment variable
A process configuration mechanism, not a secret vault.
Writable layer
Container-specific changes; survives restart of the same container but is removed with that container.
Named volume / bind mount
Docker-managed storage / a specified host path mounted into a container.

Address by caller

  • Laptop browser: uses the published host URL.
  • API container: uses db and the database port on their shared network.
  • Browser JavaScript: cannot automatically resolve private Compose service names.
  • Container to host: needs a host-reachable address; Docker Desktop supplies host.docker.internal for this use.

Persistence decision

Mount the named volume at the database image’s documented data directory. Replacements can reuse it when versions and configuration are compatible. A persistent volume is not a backup; use supported database backup and restore procedures. Publishing the database port is unnecessary for API-to-database traffic on their shared network.
