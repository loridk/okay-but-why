Episode guide

Modern JavaScript: What the Hell Happened?

A bridge for developers who already know JavaScript but learned it before ES6/ES2015. What changed, why it changed, which syntax is actually JavaScript, and what problems the newer features solve.

  • Episode 1: Wait, JavaScript Changed? JavaScript vs ECMAScript; ES6/ES2015; yearly language evolution; language vs environment/tooling; transpilation and polyfills.
  • Episode 2: var Has Left the Building let and const; block scope; hoisting and the temporal dead zone; const bindings versus mutation; and the loop-closure problem.
  • Episode 3: Why Does Everything Have an Arrow Now? Arrow function syntax, callbacks, lexical this, and the important differences between arrow functions and normal functions.
  • Episode 4: Wait, That's Just JavaScript Destructuring, spread and rest, template literals, default values, object shorthand, optional chaining, and nullish coalescing.
  • Episode 5: JavaScript Finally Learned How to Wait Callbacks, promises, async/await, the event loop mental model, fetch as an environment API, error handling, and Promise.all.
  • Episode 6: Import This, Export That ECMAScript modules, named and default exports, browser modules, CommonJS, dynamic imports, and the difference between modules and bundling.
  • Episode 7: Okay, But How Do People Write JavaScript Now? map, filter, find, some, every, and reduce; for...of versus for...in; object helpers, transformation versus mutation, chaining, and readability over cleverness.
Okay, But Why? — Tech concepts without the ceremonial fog.
