# Modern JavaScript: What the Hell Happened?

Seven-episode *Okay, But Why?* bridge series for developers who learned JavaScript before ES6/ES2015.

Each numbered folder contains:
- `master-script.md` — production script
- `companion.html` — listening companion/transcript with code cards

Audio is intentionally not included. Add each published episode's RedCircle embed to its companion page when available.

Series order:
1. Wait, JavaScript Changed?
2. `var` Has Left the Building
3. Why Does Everything Have an Arrow Now?
4. Wait, That's Just JavaScript
5. JavaScript Finally Learned How to Wait
6. Import This, Export That
7. Okay, But How Do People Write JavaScript Now?
