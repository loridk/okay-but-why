Episode guide

Web Architecture Series

Start at Episode 1 or jump directly to any Web Architecture topic. Each page includes the audio, transcript, and code cards.

  • Episode 1: What Even Is Web Architecture? Architecture as responsibilities, boundaries, and tradeoffs; use Nervous Robot Pizza Delivery to explain the reasons behind the boxes.
  • Episode 2: Client vs Server — Whose Computer Is This? Separate browser capabilities from authoritative server decisions, including validation, permissions, prices, and secrets.
  • Episode 3: The Request/Response Cycle — I Pressed Enter, Now What? Follow a URL through DNS, connections, HTTP requests, responses, redirects, and browser diagnostics.
  • Episode 4: Static Sites, Server Rendering, and the Allegedly Dead Web Compare prepared static pages and request-time server rendering; forms, sessions, progressive enhancement, and operational costs.
  • Episode 5: How We Got SPAs — The Page Refuses to Leave Why SPAs exist and which jobs move into the browser: routing, state, loading, request races, focus, and navigation.
  • Episode 6: APIs — A Boundary With a Job Description APIs as contracts covering methods, data, validation, errors, compatibility, pagination, CORS, and safe retries.
  • Episode 7: Authentication, Sessions, Cookies, and Tokens — Do You Know Me? Distinguish identity, authentication, sessions, and authorization; cookies, tokens, CSRF, expiry, and object-level permissions.
  • Episode 8: Databases and Application State — Where Does the Truth Live? Persistent state, relational models, transactions, concurrency, indexes, migrations, backups, and data ownership.
  • Episode 9: Monoliths — One Application, Several Responsibilities Organize a monolith into deliberate modules; understand coupling, shared releases, scaling, and when extraction is justified.
  • Episode 10: Microservices — Congratulations, Your Function Call Has Weather Service boundaries and independent deployment versus network failures, distributed data, events, retries, idempotency, and operational overhead.
  • Episode 11: Caching and CDNs — Yesterday's Pizza, Today's Problem Caching and CDNs as conditional reuse; freshness, validation, cache keys, invalidation, private data, and stampedes.
  • Episode 12: Scaling — More Pizza, Not Automatically More Services Measure bottlenecks before scaling; vertical/horizontal capacity, state, queues, backpressure, load testing, and graceful degradation.
  • Episode 13: SSR, CSR, SSG, and Hydration — When Does the HTML Happen? Separate where rendering happens from when it happens; SSR, CSR, SSG, hydration, islands, streaming, and hybrid choices.
  • Episode 14: Build an Architecture in Your Head — Reasons Before Rectangles Design a modest architecture from requirements, walk success and failure paths, and explain when added complexity earns its cost.
