Episode guide

React & Modern Front-End Frameworks Series

Start at Episode 1 or jump directly to any React & Modern Front-End Frameworks topic. Each page includes the audio, transcript, and code cards.

  • Episode 1: Who Asked for This? Why the Fuck Did We Need React? The coordination problem behind React; imperative DOM updates versus declarative UI, components, and the costs of a state-driven model.
  • Episode 2: Components, Props, and JSX — Whose HTML Is This? Components as functions, JSX, props, children, event callbacks, lists and keys, and accessibility inside component boundaries.
  • Episode 3: State — Why Didn’t My Variable Update the Screen? State updates and render snapshots; functional updates, derived values, controlled inputs, lifting state, and immutable changes.
  • Episode 4: Hooks and useEffect — Stop Synchronizing Nothing Hooks and closures, effects for external synchronization, dependencies and cleanup, refs, context, memoization, and custom hooks.
  • Episode 5: The React Ecosystem — Why Do I Need Seventeen Other Things? Separate React from build tools, routers, data libraries, forms, styling, testing, and other ecosystem choices.
  • Episode 6: Vue and Angular — React Is Not the Only Answer Compare React, Vue, and Angular through their component models, reactivity, platform scope, team fit, and migration costs.
  • Episode 7: React Frameworks — Why Is Next.js Standing Behind React? Why React frameworks combine routing, rendering, data, and deployment; hydration, Server Components, client boundaries, and Next.js.
  • Episode 8: Do You Actually Need a Framework? Choose tools from requirements using concrete sites and applications; weigh progressive enhancement, maintenance, performance, accessibility, and team understanding.
