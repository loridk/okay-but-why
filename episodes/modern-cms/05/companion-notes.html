Companion reference

Query selection, entity display, rendering, and cache correctness are separate jobs that cooperate to build a page.

Translate the terminology

Episode 5 reference
TermUseful mental model
Views relationshipMakes related records available to a query; multi-value joins can multiply rows.
Contextual filterReceives an argument from configured context, with explicit missing/invalid behavior.
Exposed filterA visitor-facing control for query input.
View displayA page, block, or other output of a View.
Render arrayDeferred output structure with dependencies, attachments, and other metadata.
Cache tagsDependencies used for invalidation.
Cache contextsRequest differences requiring separate variants.
Max-ageTime-based limit on reuse; other caching layers also require appropriate configuration.

Rendering map

Content → entity → chosen view mode → render array → theme system → Twig → HTML is an approximate map. A page is a tree of output, and caches or specialized elements may bypass some work.

Try the reasoning

  1. Warm the cache, edit a listed event, and request the page again.
  2. Create a new matching event to test list dependencies.
  3. Test language, permission, and relevant query-argument variants.
  4. Cross an event time boundary without an edit to test expiry.
  5. Inspect query relationships before treating duplicate rows as a presentation bug.
