Translate the terminology

Episode 7 reference
TermUseful mental model
RouteMaps a request to behavior and declares access requirements.
ControllerHandles a route and produces output or a response.
Service / containerManaged reusable object / system that constructs and supplies its dependencies.
Dependency injectionReceiving collaborators explicitly rather than locating them throughout working code.
Drupal pluginDiscoverable implementation of a plugin type; different packaging meaning from WordPress plugin.
PHP attributeLanguage-level structured metadata interpreted by a relevant API.
Symfony event subscriberRegistered behavior responding to dispatched event objects.

Legacy → modern, with exceptions

Recognize both forms in real code
PatternInterpretation
MODULE_hook() in .moduleProcedural hook implementation, still encountered in Drupal 10/11.
#[Hook(...)] on a methodOOP hook implementation supported from Drupal 11.1; follow the supported version range.
Installation/update and theme hooksDocumented procedural exceptions remain. Check the current Hook API.
Plugin annotations / attributesDiscovery varies by plugin type and Drupal version; not every annotation is interchangeable with an attribute.

Try the reasoning

  1. Read info, routing, and service definitions before following the controller.
  2. Install the demonstration module only in an existing disposable Drupal 11.1+ site.
  3. Test route access with permitted and denied users.
  4. Change the site name with caches warm and verify the greeting changes.
  5. Choose one help-hook example; do not enable duplicate implementations accidentally.
