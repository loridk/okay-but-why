Companion reference

Parameter / weight
An adjustable numerical value inside a model; distinct from a function parameter in JavaScript.
Loss
A numerical measure used during training to assess predictions against an objective.
Optimizer
The procedure that updates parameters to improve that objective.
Neural network
Connected layers of mathematical transformations, not a recreation of a human brain.
Generalization
Performance on relevant examples beyond those used for fitting.
Overfitting
Fitting training-specific patterns that do not transfer well.
Held-out data
Examples reserved for assessing performance rather than fitting or repeatedly tuning the model.

Support Assistant decision

Try an existing model before proposing foundation-model training. A small classifier, fine-tuning an existing model, and pretraining a large model are different projects. Data rights, quality, leakage, compute, expertise, and evaluation belong in the scope.
