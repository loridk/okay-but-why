Before a refund

  • Verify order, amount, currency, policy, actor, and current state.
  • Show the exact proposal in a keyboard-accessible confirmation.
  • Bind approval to the proposal; invalidate it if the proposal changes.
  • Use idempotency and reconcile uncertain outcomes with the service.
  • Return the actual transaction result, not a generated assertion.
