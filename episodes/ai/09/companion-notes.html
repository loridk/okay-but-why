State is not all chat history

Persist authoritative approval and execution records outside the model. Conversation summaries can lose details. Stored memory needs retention and access checks; old access never becomes permanent permission.

Multiple agents

Separate independent tasks only when useful. A coordinator must reconcile findings, permissions, budgets, and failures. Two models agreeing is not independent evidence if both rely on the same flawed sources. More agents add coordination and cost.
