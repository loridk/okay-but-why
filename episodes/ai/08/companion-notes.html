USB-C analogy boundary

A shared connector reduces repeated integration work. It does not guarantee feature compatibility, safe credentials, trustworthy tool descriptions, or sensible business behavior. Use a direct API integration when that is simpler.

Trust decisions

  • Inspect server provenance, permissions, credentials, and network reach.
  • Authorize actual records and operations; listing a tool is not approval.
  • Treat returned text and descriptions as potentially hostile.
  • Keep write approvals and minimal data access independent of model compliance.
