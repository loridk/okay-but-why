Read the actual job description and ask about implementation, customer contact, operations, and ownership. These titles overlap; none guarantees or excludes coding. FDE is not restricted to AI. Using a model API does not establish model-training experience.

Questions before adding AI

  1. Whose task is difficult, and what does success look like?
  2. What evidence shows the problem and current baseline?
  3. Could search, document cleanup, or deterministic code solve it?
  4. What data is accurate, current, authorized, and permitted to leave the environment?
  5. Which errors are tolerable, and which actions require enforced controls?
  6. What will representative evaluations measure?
  7. Can people inspect evidence, correct results, and reject actions accessibly?
  8. What happens during missing evidence, timeouts, and uncertain writes?
  9. Who maintains sources, integrations, quality, costs, and incidents?
  10. What evidence would make us change direction or remove the AI?

Series concept map and glossary

Foundations → context → application → retrieval and tools → optional integration/autonomy → evaluation and operations → useful delivery. Later layers depend on earlier understanding; they are not a mandatory shopping list.

AI / ML / deep learning / generative AI / LLM

Training / parameters / inference

Tokens / attention / context
Pieces of input and the computations that support generation.

Supply instructions and information; validate the resulting shape and meaning.
API / SDK / streaming
Connect an application with appropriate server and browser boundaries.
RAG / embedding / vector / chunking
Retrieve authorized evidence and supply it at inference time.
Tool / schema / authorization / approval
Model proposes; application validates, permits, and executes.
MCP / host / client / server
Standardize part of integration discovery and exchange.
Workflow / agent / state / orchestration
Choose who controls the next step and where authoritative state lives.
Eval / hallucination / trace / regression
Measure quality and failures, enforce boundaries, investigate changes.
Hosting / open-weight / quantization / caching
Operate an evaluated dependency within cost, privacy, and reliability constraints.

Outcome, honestly stated

The fictional journey illustrates applied engineering. It supplies no measured customer results, production deployment, or professional credential. The real requirement remains improving support work safely and measurably.
