Companion reference

Start with the support task: help staff find relevant evidence and draft an answer they can verify.

AI
A broad field concerned with computer capabilities associated with intelligence.
Machine learning
Methods that use data to adjust models rather than manually specify every task rule.
Deep learning
Machine learning using multilayer neural networks.
Generative AI
Systems that generate content such as text, images, or audio.
LLM
Large language model; a learned model used for language-related tasks.
Inference
Using a trained model to compute an output.
Product
The interface, model, integrations, controls, and operations experienced together.

Historical context

Explicit rules and symbolic approaches preceded today’s generative products and remain useful. Statistical learning, greater data availability, more compute, and deep-learning advances contributed to modern capabilities. This was not a single moment when computers began to “think.”

Define the experiment

  • Baseline: observe manual search and answer preparation.
  • Trial: invented question plus approved sample policy → reviewed draft.
  • Check: preserved conditions, missing facts, unsupported claims, review effort.
  • Alternative: better search, document ownership, or a deterministic form.
