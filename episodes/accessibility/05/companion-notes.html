Companion reference

These are selected WCAG 2.2 reference points, not a complete checklist or conformance claim. Read each linked criterion for its conditions and exceptions.

Visual and interaction reference values

Text contrast — 1.4.3, AA
Generally 4.5:1 for normal text and 3:1 for large text. Large means at least 18pt regular (24 CSS px) or 14pt bold (about 18.67 CSS px), or equivalent sizing for relevant scripts. Exceptions include incidental text and logotypes. Check actual foreground/background combinations and states. Contrast Minimum.
Essential non-text visuals — 1.4.11, AA
Relevant visual information identifying controls/states and meaningful graphics needs 3:1 against adjacent colors, subject to the criterion's exceptions. A passing text color does not establish this. Non-text Contrast.
Color is not the only signal — 1.4.1, A
Add meaningful text, shape, pattern, or another channel. “Postal code is required” communicates more than a red border. Use of Color.
Resize text — 1.4.4, AA
Support resizing text up to 200% without loss of content/function, with specified exceptions. Resize Text.
Reflow — 1.4.10, AA
For vertically scrolling content, check an effective width of 320 CSS px without loss or required scrolling in both dimensions, except content needing two-dimensional layout. A 1280-CSS-px-wide starting viewport at 400% zoom is a common test. Horizontally scrolling content has the corresponding 256-CSS-px-height condition. Reflow.
Text spacing — 1.4.12, AA
Support user overrides together: line height 1.5 times font size, paragraph spacing 2 times font size, letter spacing 0.12 times font size, word spacing 0.16 times font size, without loss. These are supported overrides, not required default styling. Text Spacing.
Targets — 2.5.8, AA
24×24 CSS px minimum or applicable exceptions. The spacing exception uses 24px-diameter circles centered on undersized targets: circles must not overlap other targets or another undersized target's circle. Other exceptions cover equivalent controls, inline targets, unmodified user-agent controls, and essential presentation. Larger comfortable targets remain useful. Target Size Minimum. Target Size Enhanced (AAA) uses 44×44 CSS px with its own exceptions.

Review states, not just screenshots

  • Empty, focused, filled, autofilled, invalid, corrected, loading, successful, and unavailable states.
  • Enlarged text, narrow effective viewport, user text spacing, and long labels/content.
  • Default and alternate themes, focus visibility, background images, overlays, and sticky content.
  • Reduced motion, touch input, keyboard operation, and persistent labels after entry.

Error recovery recipe

  1. Identify the affected field and the problem in useful visible text.
  2. Associate the help/error with the control; keep its accessible name clear.
  3. Update invalid state and remove obsolete errors when corrected.
  4. Use a deliberate summary/focus/announcement strategy rather than competing mechanisms.
  5. Preserve correct entries and validate again on the server.

Motion and understandable UX

Honor prefers-reduced-motion for relevant CSS and JavaScript motion. Keep essential information available without animation. Separately consider pause/stop controls and flashing hazards. Clear labels, consistent navigation, predictable effects, and recovery reduce avoidable cognitive demands.
